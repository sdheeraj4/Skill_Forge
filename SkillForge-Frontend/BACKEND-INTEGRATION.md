# Backend Integration Status

Integration is complete.

Frontend features connected to Express/MySQL:

- Registration, login, logout and session authentication
- Profile and interests
- 10-course catalogue and course details
- Enrollment and My Learning
- 3-module course progress
- Recommended YouTube lectures
- 10-question final course assessment
- Performance classification and weak-module detection
- Adaptive course recommendations
- Dashboard analytics
- Skill profile
- Candidate report card

API base URL: `http://127.0.0.1:5000/api`
